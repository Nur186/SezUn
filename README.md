# SezUn

**SezUn** (сезу + үн) — көру қабілеті шектеулі адамдарға арналған тәжірибелік веб прототип. Компьютер камерасынан көріністі алып, YOLO арқылы таныс нысандарды іздейді және олардың атауы мен кадрдағы орнын қазақша дауыстап айтады.

*SezUn ("Sense + Voice") is an experimental web prototype that detects objects with YOLO and describes their name and position aloud in Kazakh.*

> **Қауіпсіздік:** бұл тәжірибелік MVP жолда жүруге немесе кедергілерден қауіпсіз өтуге арналмаған. Нысанды қате тануы не өткізіп алуы мүмкін, қашықтықты өлшемейді. Ақ таяқ пен басқа көмекші құралдарды алмастырмайды. Тек қауіпсіз, жабық ортада сынаңыз.

## Техникалық тапсырма (ТЗ)

### 1. Жобаның мақсаты

Камерадағы көріністі нысандарға талдап, нәтижені қазақша дауыспен жеткізетін қарапайым әрі жеңіл веб прототип жасау. MVP машиналық оқыту (YOLO) арқылы компьютерлік көру идеясының жұмыс істей алатынын көрсетуі тиіс.

### 2. Мақсатты аудитория

- Көру қабілеті шектеулі адамдар (тек сынақ және зерттеу мақсатында, көмекшісімен бірге).
- Әзірлеушілер, зерттеушілер, студенттер, прототипті бағалайтын мамандар.

### 3. Міндеттер

1. Браузер арқылы камераға қол жеткізу және кадрларды алу.
2. Кадрларды жергілікті серверге жіберіп, YOLO арқылы нысандарды анықтау.
3. Әр нысанның кадрдағы орнын анықтау: сол, орта немесе оң.
4. Нәтижені экранда көрсету және қазақша дауыстап айту.
5. Қолданушының камераны қосуы мен тоқтатуын қамтамасыз ету.

### 4. Функционалдық талаптар

| № | Талап | Басымдық |
|---|-------|----------|
| F1 | «Камераны қосу» батырмасы камераға рұқсат сұрап, видео ағынды бастайды | Міндетті |
| F2 | «Тоқтату» батырмасы камераны толық өшіреді | Міндетті |
| F3 | Кадр шамамен 1,3 секунд сайын серверге жіберіледі | Міндетті |
| F4 | Сервер YOLO арқылы нысандарды анықтайды, ең ірі көрінген нысандарды таңдайды | Міндетті |
| F5 | Әр нысан үшін атауы мен орны (сол / орта / оң) қайтарылады | Міндетті |
| F6 | Нәтиже бетте мәтін түрінде көрсетіледі | Міндетті |
| F7 | Нәтиже браузердің сөйлеу қызметі (Web Speech API, `kk-KZ`) арқылы қазақша дыбысталады | Міндетті |
| F8 | Бірдей нәтиже қайталанып үздіксіз айтылмайды (қайталауды азайту) | Қалаулы |
| F9 | Камера индексі `CAMERA_INDEX` ортасындағы айнымалысы арқылы таңдалады | Қалаулы |
| F10 | Қазақша дауыс жоқ болса, қолданушыға түсінікті ескерту көрсетіледі | Қалаулы |

### 5. Функционалды емес талаптар

- **Құпиялылық:** видео кадрлар дискіге жазылмайды және сыртқы желіге жіберілмейді. Өңдеу тек жергілікті жерде жүреді.
- **Өнімділік:** кадрды өңдеу мен жауап қайтару CPU-да да қолайлы мерзімде жүруі тиіс, нысандарды хабарлау кідірісі бірнеше секундтан аспауы керек.
- **Үйлесімділік:** Windows, Python 3.10 немесе 3.11, заманауи Chromium негізіндегі браузер.
- **Қолжетімділік:** интерфейс үлкен батырмалармен, анық контрастпен және экран оқу құралдарына сай белгілермен жасалады.
- **Қарапайымдылық:** орнату мен іске қосу бірнеше команда арқылы орындалады.

### 6. Техникалық стек

- **Backend:** Python, Flask, Ultralytics YOLO (әдепкі COCO үлгісі).
- **Frontend:** HTML, CSS, JavaScript, `getUserMedia` (камера), Web Speech API (дыбыстау).
- **Тәуелділіктер:** `requirements.txt`.

### 7. Архитектура

```
Камера ──► Браузер (JS) ──кадр──► Flask сервері ──► YOLO
                ▲                                     │
                └────── нысан атауы + орны ◄──────────┘
                │
                ▼
      Экранда көрсету + қазақша дыбыстау
```

1. Браузер кадрды алып, шамамен 1,3 секунд сайын серверге жібереді.
2. Сервер кадрды YOLO-ға береді және нысан тізімін қайтарады (атауы, сенімділік, рамка координаттары).
3. Нысан рамкасының көлденең орталығына қарап орны анықталады: кадрдың сол үштен бірі — «сол», ортаңғы — «орта», оң жағы — «оң».
4. Браузер нәтижені көрсетіп, дауыстап айтады.

### 8. API (жоба)

| Әдіс | Жол | Сипаттама |
|------|-----|-----------|
| GET | `/` | Негізгі бет |
| POST | `/detect` | Кадрды қабылдап, нысандар тізімін JSON ретінде қайтарады |

Жауап үлгісі:

```json
{
  "objects": [
    { "label": "person", "label_kk": "адам", "position": "center", "confidence": 0.87 }
  ]
}
```

### 10. Қамтылмайтын мүмкіндіктер (MVP шегінен тыс)

## Іске қосу

Python 3.10 немесе 3.11 орнатып, жоба бумасында терминал ашыңыз:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Сосын браузерде http://127.0.0.1:5000 бетін ашып, **Камераны қосу** батырмасын басып, камераға рұқсат беріңіз. Бірінші іске қосқанда YOLO салмақтары автоматты түрде жүктеледі. **Тоқтату** батырмасы камераны өшіреді.

Камераны браузер қауіпсіз деп санайтын ортада ашыңыз: `localhost` пен `127.0.0.1` арқылы жергілікті іске қосу жарайды. Сайтты желідегі басқа құрылғыдан ашсаңыз, HTTPS қажет болуы мүмкін.

Камера таңдау үшін:

```powershell
$env:CAMERA_INDEX = "0"
python app.py
```

Қолданылған дауыс браузерге тәуелді; қазақша дауыс болмаса, құрылғының дыбыс/сөйлеу баптауынан тексеріңіз.

## Қалай жұмыс істейді

- Браузер камера кадрын шамамен 1,3 секунд сайын жергілікті Flask серверіне жібереді.
- Python жағындағы Ultralytics YOLO ең ірі көрінген нысандарды анықтайды.
- Сайт анықталған нысан мен сол/орта/оң орнын көрсетеді; қазақша дыбыстау браузердің сөйлеу қызметі арқылы орындалады.
- Видео кадрлар дискіге жазылмайды, желіге жіберілмейді.

## Шектеулер

- YOLO-ның әдепкі COCO үлгісі тек таныс нысандардың шектеулі жиынын таниды. Мысалы, баспалдақ пен шұңқырды сенімді анықтамайды.
- Бір RGB камера нақты қашықтықты өлшемейді. Нысанның ірі көрінуін қауіпсіздік сигналы деп қабылдамаңыз.
- Қазақша сөйлеу қолжетімділігі браузер мен операциялық жүйеге байланысты.
