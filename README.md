# ML Project — камералық көмекші прототипі

Камерадан алынған көріністегі нысандарды анықтап, қысқа қазақша аудио ескерту беретін көмекші құрылғының бастапқы бағдарламасы.

> **Қауіпсіздік туралы:** бұл — зертханалық MVP. Ол жолды қауіпсіз бағдарлауға арналмаған және ақ таяқ, бағыттаушы ит не басқа көмекші құралдарды алмастырмайды. Нысанды тану мен қашықтықты бағалау қателесуі мүмкін. Алғашқы сынақтарды тек қауіпсіз, жабық ортада және көмекшімен бірге өткізіңіз.

## Қазіргі MVP

- OpenCV арқылы веб-камерадан кадр оқу.
- Ultralytics YOLO-ның шағын COCO моделінен нысандарды табу.
- Нысанның кадрдағы сол/орта/оң орнын және шамамен үлкендігін анықтау.
- Бір нысанды қайта-қайта айта бермес үшін дыбыс ескертуіне үзіліс қою.
- `pyttsx3` арқылы орнатылған дауыс көмегімен офлайн сөйлеу.

Қазір бағдарлама нақты метрмен қашықтықты өлшемейді. Кадрдағы нысанның үлкен көрінуі тек жуық белгі ретінде қолданылады.

## Іске қосу

Python 3.10 немесе 3.11 ұсынылады.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python -m assistive_vision
```

Бірінші іске қосқанда YOLO салмақтары `yolov8n.pt` Ultralytics арқылы жүктеледі. Камераны таңдау үшін:

```powershell
$env:CAMERA_INDEX = "0"
python -m assistive_vision
```

Терезені жабу үшін `q` басыңыз. Ескерту дыбысы компьютерде немесе құлаққапта шығады.

## Келесі хөгжүүлэлт

1. Қазақша сөйлеу сапасын мақсатты телефон/тақтада тексеріп, TTS дауысын ауыстыруға болатын интерфейс жасау.
2. Ультрадыбыстық немесе ToF тереңдік сенсорын қосып, метрмен қашықтық пен жақындау жылдамдығын өлшеу.
3. Ескертулерді басымдықпен басқару: соқтығысу қаупі, кедергі бағыты, содан кейін қосымша сипаттама.
4. Далаға шығар алдында көру қабілеті төмен пайдаланушылармен бірлесіп сынау, қате өткізіп алу мен жалған дабылдарды өлшеу.
5. Батарея, кідіріс, камера бұрышы және ашық құлаққа арналған сүйек өткізгіш құлаққапты бағалау.

## Шектеулер

- COCO жиыны барлық маңызды нысанды танымайды (мысалы, баспалдақ/шұңқыр сенімді танылмайды).
- Бір RGB камера абсолютті қашықтық бермейді.
- `pyttsx3` жүйеде орнатылған дауысқа тәуелді; қазақ тіліндегі дауыс қолжетімді болмауы мүмкін.
- Құлаққап қоршаған орта дыбысын толық жаппауы керек. Ашық құлақ/сүйек өткізгіш құрылғы қауіпсіздеу зерттеу бағыты.
