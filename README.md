# Көру көмекшісі

Компьютер камерасынан көріністі алып, YOLO арқылы таныс нысандарды іздейтін және атауы мен кадрдағы орнын қазақша дауыстап айтуға арналған веб прототип.

> **Қауіпсіздік:** бұл тәжірибелік MVP жолда жүруге немесе кедергілерден қауіпсіз өтуге арналмаған. Нысанды қате тануы не өткізіп алуы мүмкін, қашықтықты өлшемейді. Ақ таяқ пен басқа көмекші құралдарды алмастырмайды. Тек қауіпсіз, жабық ортада сынаңыз.

## Іске қосу

Python 3.10 немесе 3.11 орнатып, жоба бумасында терминал ашыңыз:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Сосын браузерде [http://127.0.0.1:5000](http://127.0.0.1:5000) бетін ашып, **Камераны қосу** батырмасын басып, камераға рұқсат беріңіз. Бірінші іске қосқанда YOLO салмақтары автоматты түрде жүктеледі. Тоқтату батырмасы камераны өшіреді.

Камераны браузер қауіпсіз деп санайтын ортада ашыңыз: `localhost` пен `127.0.0.1` арқылы жергілікті іске қосу жарайды. Сайтты желідегі басқа құрылғыдан ашсаңыз, HTTPS қажет болуы мүмкін.

Камера таңдау үшін:

```powershell
$env:CAMERA_INDEX = "0"
python app.py
```

Қолданылған дауыс браузерге тәуелді; қазақша дауыс болмаса, құрылғының дыбыс/сөйлеу баптауынан тексеріңіз.

## Қалай жұмыс істейді

- Браузер камера кадрын шамамен 1,3 секунд сайын жергілікті Flask серверіне жібереді.
- Python жағындағы Ultralytics YOLO ең ірі көрінген нысандарды анықтайды.
- Сайт анықталған нысан мен сол/орта/оң орнын көрсетеді; қазақша дыбыстау браузердің сөйлеу қызметі арқылы орындалады.
- Видео кадрлар дискіге жазылмайды, желіге жіберілмейді.

## Шектеулер

- YOLO-ның әдепкі COCO үлгісі тек таныс нысандардың шектеулі жиынын таниды. Мысалы, баспалдақ пен шұңқырды сенімді анықтамайды.
- Бір RGB камера нақты қашықтықты өлшемейді. Нысанның ірі көрінуін қауіпсіздік сигналы деп қабылдамаңыз.
- Қазақша сөйлеу қолжетімділігі браузер мен операциялық жүйеге байланысты.
